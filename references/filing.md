# 申报准备、核对与回执

## 交付底稿

记录匿名事项编号、主体类型、所在地、所属期、税种、征收方式、来源引用与本次核对日期。金额与证据保存在私有工作目录；不把实际客户资料放进技能或公开 Git 仓库。

每个税种使用一种结论：资料不足、需要据实填写非零栏目、需要进一步核对、超出本版范围、清单未列应报、零业务候选。最后一项只允许继续核对，不表示税额已确定。

底稿要说明收入是否包含未开票、免税、现金、个人代收、平台结算，以及是否存在预收款、退款、费用、结转和已预缴税。预收会员费等需按业务与现行规则判断纳税义务，不能机械按到账或消费时间归属。

## 按实际页面办理

从税务总局或主管税务机关官网进入当地电子税务局；经营所得使用自然人电子税务局相应经营所得功能。先检查身份、主体和本期待办，不假定各地菜单一致。

| 阶段 | 必须保留的事实 | 尚不能声称 |
| --- | --- | --- |
| 资料整理 | 来源范围、缺项、未决分类 | 资料齐全或符合零申报 |
| 预览核对 | 税种、所属期、全部非零栏目、扣除/优惠/结转、预缴、预计应补退 | 已提交或已缴税 |
| 提交后 | 受理状态、回执编号或脱敏结果引用 | 超时或页面按钮变化即成功 |
| 独立回查 | 申报记录中的主体、期间、税种与状态 | 一个税种成功即全部完成 |
| 缴款核查 | 待缴、扣款中、成功或确实无本次缴款事项 | 申报成功即缴款成功 |

实际提交应在用户已有授权范围内进行；若尚未授权，展示具体预览后再请求。仅“做一个 skill”不授权替任何真实纳税人提交申报。

## 其他待办

- 经营所得年度汇算与多处经营所得汇总单列；经营所得年度汇算不同于个人综合所得汇算。
- 工资个税扣缴、附加税费、印花税、社保、财务报表报送依真实义务保留。
- 工商年报属于另一业务，不因税务申报完成而自动完成。
- 历史欠报、重复申报、更正、停复业、注销、预填冲突先处理；不能通过清零覆盖。

可使用以下人工记录结构；本版脚本不会生成“成功”回执：

```text
税种 / 所属期：
预览核对依据：
用户授权范围或确认记录：
提交结果 / 时间：未操作
回执引用：未取得
独立回查结果：未核查
缴款状态：未核查
其他税费及年度待办：
```
